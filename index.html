1. Phone Split & Uniqueness Architecture
In previous releases, duplicate rows existed for the same phone number across various roles (e.g. one row for User, another row for Driver). In this refactor:
  • A single active record in users table holds all assigned roles via model_has_roles.
  • Composite index users_phone_split_index (country_code, mobile_number) ensures instant O(1) indexed lookups without full-table wildcard scans.
  • All duplicate legacy accounts have been reconciled or soft-deleted (deleted_at IS NOT NULL), maintaining 100% strict phone uniqueness.
